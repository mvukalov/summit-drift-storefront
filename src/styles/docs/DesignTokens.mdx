# Design Tokens

The visual language of Summit Drift Outfitters. Every value on this page is read live from
`src/styles/tokens.scss`, so this page is the source of truth for review.

Tokens come in two tiers. **Primitives** hold raw values (`--color-clay`). **Semantic** tokens
name a purpose (`--color-accent`) and point at a primitive. Components use semantic tokens only.

`--color-clay` (#B5623F) is 3.7:1 on cream, below WCAG AA for text. Text and small fills use
`--color-clay-dark` (4.9:1). Plain clay is kept for large or decorative use only.

## Typography

Headings use **Libre Baskerville**, body and UI text use **IBM Plex Sans**. Both are
self-hosted by `next/font`. `h1` steps up to `--font-size-4xl` from the `lg` breakpoint.
